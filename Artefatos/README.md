# Artefatos do projeto

Este diretório mantém os artefatos do projeto.

Abaixo estão listados os artefatos produzidos, com suas localizações e descrições do conteúdo:

- `/Diagramas`: Contém diagramas do projeto, como diagramas de caso de uso e diagramas de classe.

- `/Requisitos`: Contém documentos de requisitos do projeto, incluindo especificações funcionais e não funcionais e regras de negócio.

- [Sprint 2](sprint-2.md): Mapeamento do UML para o monólito Spring Boot, decisões de persistência e pendências.

- [Arquitetura Spring](Diagramas/arquitetura-spring.md): Diagramas Mermaid das camadas e das entidades adaptadas para JPA.
